# Graphical Algorithm Visualizer

An interactive, modern educational platform designed to help developers and students understand core computer graphics algorithms through step-by-step visualizations.

## 🚀 Features

- **Modern & Premium UI:** Designed with a sophisticated dark theme, glassmorphism, and responsive layouts inspired by top-tier developer tools.
- **Interactive Visualizations:** Watch algorithms execute line-by-line and pixel-by-pixel on a custom HTML canvas.
- **Live State Tracking:** Monitor variable changes (dx, dy, error margins, etc.) in real-time as the algorithms progress.
- **Algorithm Information:** View the time/space complexities and clean pseudocode for every algorithm.
- **Responsive Design:** Optimized for desktops, tablets, and modern web environments.

## 🧮 Implemented Algorithms

The platform currently includes the following implementations:
- **DDA (Digital Differential Analyzer)** Line Drawing
- **Bresenham** Line Drawing
- **Midpoint Circle** Drawing

*(More algorithms like Scanline Fill, Flood Fill, and clipping can be easily added to the modular architecture).*

## 🛠️ Technology Stack

- **Framework:** [React 18](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v3](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router v6](https://reactrouter.com/)
